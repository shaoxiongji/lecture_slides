Count like a ViT

A vision transformer cuts the image into square patches and turns each one into a token. Apples do not respect patch borders. Turn on the patches, hover an apple, and compare three ways of counting: patch by patch, by area, and object by object.

Hover or tap an apple to see how many patch tokens it is split into.

One apple, many tokens

Patch tokens describe texture and layout inside a square. Nothing in the representation says “this is one object”, so the one-to-one link between things and tokens is missing.

Counting becomes estimation

Summing patch statistics behaves like density estimation: about right for the amount of apple, unreliable for the number of apples, and worst where apples overlap.

Look step by step

People count with object permanence and an increment loop. Chain-of-Look turns that into visual key-steps the model must take, one object at a time.

Toy model, not a real ViT: the two patch-level counters show two ways patch statistics go wrong (fragmentation and occlusion). Apple layout is generated, not taken from the original image.
